# React + Next.js + TypeScript

## Coding Standards (Frontend)

- Framework: React with Next.js
- Language: strict TypeScript only
- Source file extensions: `.ts` and `.tsx`

## Scripts

- `npm run dev` starts Next.js development server.
- `npm run build` builds the production bundle.
- `npm run start` starts the production server.
- `npm run lint` runs lint checks.

## Routing

- The app uses Next.js pages routing.
- Route files use the `*.page.tsx` convention.
- UI page components can live alongside route wrappers in `src/pages/`.
